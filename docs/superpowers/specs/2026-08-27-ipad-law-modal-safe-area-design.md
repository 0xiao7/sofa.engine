# iPad 法條小窗與頂部安全區設計

## 目標

在選擇題解析中，所有可辨識的法規名稱與條號都可點擊，並在目前題目頁內開啟既有法條小窗；同時讓 iPad 網頁、加入主畫面與原生殼層的頂部導覽列都避開系統狀態列。

## 現況與根因

- 最新主線已有 `quiz-article-panel`，可在頁內載入完整條文、按叉關閉並保留原題。
- 解析連結辨識目前可處理部分「法規名稱＋條號」，但「所得稅法第 34 條、第 51 條」這類連續引用，以及資料庫內容常見的「《所得稅法》第 4-1 條」書名號與子條號格式，不一定會轉成連結。
- `sofa.css` 只在窄於 760px 或 `ios-reader-app` 類別下替 `.topbar` 加入 `safe-area-inset-top`。iPad 橫向與直向通常寬於 760px，因此截圖中的系統時間列會與導覽列共用頂部空間。

## 設計

### 法條引用

- 新增共用 `law-crossref.js` 作為唯一法條辨識與條號正規化規則；查詢頁與題目頁只提供各自的小窗連結樣板，不再各維護一套正規表示式。
- 保留既有 `quiz-article-panel` 與 `openQuizArticlePanelByTarget()`，不另開分頁。
- 擴充 `linkifyLawRefs()`：同一句已辨識出法規名稱後，緊接的「、第 N 條」沿用同一法規名稱；並支援 `《法規名稱》第 N 條`、`第 N-M 條` 與 `第 N 條之 M`。
- 每個連結保留 `href` 作為無 JavaScript 備援，但正常點擊由頁面事件攔截並開啟小窗。
- 小窗可由右上角 ×、背景或 Escape 關閉；關閉後原題、答案與捲動位置不變。
- 無法可靠辨識法規名稱或條號時維持純文字，不建立猜測連結。
- 條號一律正規化成資料庫可比對的形式：全形數字轉半形、去除前導零，並將 `4-1` 與 `4條之1` 統一為 `4之1`。

### 法條引用顯示標準

- 採用資料庫既有標題的「之」格式作為唯一畫面格式；例如資料庫 `§ 04之1` 對外顯示為 `第4條之1`，不顯示 `第4-1條`。
- 輸入與舊內容仍寬鬆接受 `4-1`、`4之1`、`第4-1條`、`第4條之1`，辨識後全部轉成同一個內部條號 `4之1`。
- 單一引用顯示為 `《所得稅法》第4條之1`。
- 同一法規的連續引用顯示為 `《所得稅法》第3條、第4條之1、第8條`，法規名稱只出現一次。
- `同法第13條`、`本法第13條` 可作為輸入，但必須先解析為目前法規的完整名稱；產生連結時不得把「同法」或「本法」當成資料庫法規名稱。
- 連結文字統一不改變資料庫查詢目標：畫面使用正式引用格式，`data-law` 與 `data-art` 分別保存完整法規名稱及正規化條號。

### 採用方案

- 不批次改寫資料庫既有解析文字，避免大範圍內容遷移與歷史資料風險。
- 不保留來源文字的 `4-1` 顯示，因為會造成同一畫面出現兩種子條號格式。
- 在共用 `law-crossref.js` 的輸出層統一連結文字；這能同時修正查詢頁與題目頁，並保留對舊資料格式的相容性。

### 頂部安全區

- 共用 `.topbar` 的基礎樣式直接加入 `env(safe-area-inset-top, 0px)`，不再依賴 760px 媒體查詢。
- 手機與原生殼層保留原本較緊湊的 padding 覆寫，各層只計算一次安全區。
- 選擇題法條小窗的桌面／iPad 上緣同步加上安全區，避免小窗覆蓋加高後的導覽列。

## 驗收標準

- 「所得稅法第 34 條、第 51 條」會產生兩個可點擊連結，兩者皆指向所得稅法的正確條號。
- 「《所得基本稅額條例》第 3 條／第 8 條」、「《所得稅法》第 4-1 條／第 73-1 條」與「《國際金融業務條例》第 13 條」共產生五個正確連結。
- 輸入 `《所得稅法》第4-1條` 與 `《所得稅法》第4條之1` 時，兩者產生相同的 `data-art="4之1"`，畫面文字皆為 `《所得稅法》第4條之1`。
- 輸入 `《所得稅法》第3條、第4-1條、第8條` 時，畫面輸出恰為 `《所得稅法》第3條、第4條之1、第8條`，且三個條號分別可點擊。
- 「營利事業所得稅查核準則第 77 條」可點擊並開啟既有站內法條小窗。
- 點擊不呼叫 `window.open`、不更換頁面；按 ×、背景或 Escape 可關閉。
- `.topbar` 在不受 760px 限制的基礎規則中包含 `safe-area-inset-top`。
- iPad 橫向 1280×960 與直向 768×1024 的頂部導覽列不與系統狀態列重疊。
- 全部現有 Node 合約測試維持通過。
- `dashboard.html` 與 `quiz.html` 必須載入同一個 `law-crossref.js`，且兩邊的連結函式都委派給 `SoFaLawRefs.linkify()`。
